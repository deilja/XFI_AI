# XFI AI

AI-ядро экосистемы XFI для анализа, диагностики и автоматизации технической поддержки и инфраструктуры.

## Цели

- единый AI-модуль для проектов XFI;
- анализ логов и технических ошибок;
- диагностика VPS, VPN/Xray и сервисов;
- безопасная работа с конфигурациями без раскрытия секретов;
- структурированные ответы и рекомендации;
- расширяемая архитектура для подключения Telegram-ботов и внешних сервисов.

## Принципы

1. Сначала диагностика, затем изменение конфигурации.
2. Секреты и токены не должны попадать в логи.
3. Опасные операции выполняются только после явного подтверждения.
4. Все действия должны быть проверяемыми и журналируемыми.
5. Провайдер AI должен быть заменяемым.
